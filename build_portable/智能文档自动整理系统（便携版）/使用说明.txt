智能文档自动整理系统（便携版）使用说明
==========================================

一、运行环境
- 本软件为 Windows 便携版，目标电脑无需安装 Python、无需联网安装任何组件。
- 要求：Windows 10 / 11（64 位）。

二、使用方法
1. 将整个文件夹复制到目标电脑任意位置（建议放在 D 盘或用户目录，避免放在系统盘保护目录）。
2. 双击「启动.bat」。
3. 等待约 1~3 秒，系统会自动打开浏览器进入使用界面（地址 http://127.0.0.1:8000）。
4. 使用完毕后，回到启动窗口按回车键，系统即停止。
   （也可以直接关闭启动窗口，服务随之停止。）

三、首次使用提示
- 系统默认无访问密码。如需防止局域网内他人访问（含 AI Key 配置），
  请进入「设置 → 手机接收」设置访问密码。
- AI 辅助识别默认关闭（未配置 AI Key 时走纯规则识别）。
  如需使用 AI 辅助判断，请在「设置 → 识别能力」中填写 API 地址、模型与 Key 后保存。
- 本地 OCR 识别已内置，扫描件/图片可离线识别，不消耗 AI。

四、文件存放位置
- 归档文件：app\data\documents（按「分类/年/月」存放）
- 待整理文件：app\data\inbox（把要整理的文件放这里，或网页上传）
- 数据库：app\data\database\app.db（记录所有文档、字段、日志，请勿删除）
- 如需备份：备份整个 app\data 文件夹即可。

五、常见问题
- 打不开页面：请确认 8000 端口未被其他程序占用；可关闭其他程序后重试。
- 想换端口：修改「启动.bat」所在目录下 launch.py 中的 PORT 值。
- 手机访问：手机与电脑连同一 WiFi，浏览器打开 http://电脑IP:8000 即可上传文件。
- 邮箱接收：在「设置 → 手机接收」中填写 IMAP 配置（需在邮箱开启 IMAP 并生成授权码）。

六、升级说明
- 本便携包是自包含的。如需更新程序，用新版本替换 app\backend 与 app\frontend\dist
  目录即可（保留 app\data 不清空，数据不丢失）。
