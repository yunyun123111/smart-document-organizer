# 对账核对范围：上游三项 / 下游两项

日期：2026-11-13
适用业务线实测：`YWX202605130004`（云创总合同 · 法瑞 · PB粉）

## 一、口径

| 方向 | 核对项 | 核对内容 |
|---|---|---|
| 上游 | 结算单 | 结算单识别金额 = 台账采购结算金额（数字准不准） |
| 上游 | 发票 | 发票合计 = 采购结算金额 |
| 上游 | 付款 | 付款凭证合计 = 台账付款额；付款额与结算额的差额单独提示 |
| 下游 | 结算单 | ① 结算单金额 = 台账销售结算（数字准不准）② 销售结算 − 采购结算 = 利息（应收/实收任一命中即勾稽通过）③ 结算金额 = 发票合计 |
| 下游 | 发票 | 发票合计 = 销售结算金额 |

不在核对范围（仍进 2×5 矩阵展示资料齐套情况，但**不产生任何差异**）：
- 合同（上下游）
- 货权单/出库单（上下游）
- 下游回款（收付款回单）—— 回款明细由人工表单独提供，到表后再接

差异标注后单独处理：沿用既有 `POST /api/reconciliation/reports/{business_no}/resolve`（处理/忽略），差异不影响“已对齐”之外的统计口径。
